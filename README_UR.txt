دارالعلوم اسلامیہ بفہ — مینجمنٹ سسٹم V3 (قابلِ ترمیم ابتدائی ورژن)

ادارے کا نام: Darul Uloom al Islamia Baffa
رنگ: نیوی بلیو، گولڈ، سفید
زبان: اردو / RTL

اس ورژن میں نئی سہولیات:
1) طلبہ، حاضری، فیس، مالیات، اساتذہ اور امتحانات کے ریکارڈ کی ترمیم اور حذف۔
2) ایپ کی ترتیب: ادارے کا نام، ذیلی عنوان، نیوی بلیو اور گولڈ رنگ تبدیل کریں۔
3) شعبوں کی فہرست اپنی ضرورت کے مطابق تبدیل کریں۔
4) ڈیٹا بیک اپ JSON میں ڈاؤن لوڈ اور بیک اپ واپس درآمد کرنے کی سہولت۔
5) ایڈمن سیٹنگز سے HTML سورس کوڈ ڈاؤن لوڈ کیا جا سکتا ہے۔
6) مقامی ڈیٹا IndexedDB میں محفوظ؛ انٹرنیٹ نہ ہو تب بھی اسی ڈیوائس پر اندراج ممکن۔

ایپ کھولنے کا طریقہ:
- ZIP فائل Extract کریں۔
- dul_baffa_v2/public/index.html کو Chrome یا دوسرے جدید براؤزر میں کھولیں۔
- بہتر PWA تجربے اور متعدد دفاتر کے لیے اسے HTTPS ویب ہوسٹنگ پر چلانا ہوگا۔

ریکارڈ میں ترمیم:
- متعلقہ شعبہ کھولیں۔
- ریکارڈ کی قطار میں 'ترمیم' دبائیں۔
- ہر فیلڈ کی موجودہ قدر سامنے آئے گی؛ تبدیلی کرکے OK کریں۔
- حذف کرنے سے پہلے تصدیق پوچھی جائے گی۔

ایپ کے ڈیزائن/سافٹ ویئر میں ترمیم:
- ایپ کے اندر 'ایپ کی ترتیب' سے HTML سورس کوڈ ڈاؤن لوڈ کریں۔
- موبائل پر Acode جیسے HTML code editor یا کمپیوٹر پر Visual Studio Code میں فائل کھولیں۔
- CSS حصہ ڈیزائن/رنگ، HTML حصہ اسکرینز، اور JavaScript حصہ کام/منطق کنٹرول کرتا ہے۔
- تبدیلی کے بعد نئی index.html فائل ہوسٹنگ میں اپلوڈ کریں یا براؤزر میں کھول کر ٹیسٹ کریں۔
- بہتر ہے کہ اصل فائل کی ایک نقل محفوظ رکھیں۔

اہم حدود اور سکیورٹی:
- یہ V3 ابتدائی قابلِ ترمیم ڈیمو ہے، production-ready مرکزی نظام نہیں۔
- موجودہ براؤزر ایپ کا ڈیمو کردار منتخب کرنے والا کنٹرول حقیقی لاگ اِن یا سکیورٹی نہیں ہے۔
- مختلف دفاتر کے کمپیوٹرز/موبائلز کے درمیان حقیقی مشترکہ ڈیٹا کے لیے HTTPS ہوسٹنگ، PostgreSQL سرور، حقیقی لاگ اِن، سرور سائیڈ اجازتیں، مکمل sync/merge اور conflict resolution مکمل کرنا ضروری ہے۔
- موجودہ API کا sync endpoint واقعات محفوظ کرتا ہے؛ ابھی انہیں تمام master tables میں خودکار طور پر merge نہیں کرتا۔
- RFID مشین، رسیدوں کی قانونی/مسلسل نمبرنگ، SMS/WhatsApp، اور مکمل تنخواہ/زکوٰۃ لیجر کی جانچ و تکمیل باقی ہے۔
- اصل طلبہ یا مالیاتی ڈیٹا داخل کرنے سے پہلے فرضی ڈیٹا سے ٹیسٹ کریں اور بیک اپ لازماً رکھیں۔

سرور فائلیں:
- server/schema.sql: PostgreSQL کا ابتدائی schema
- server/server.js: ابتدائی Express API، login اور role permissions
- server/.env.example: ماحول کی مثال

نوٹ: کسی بھی حقیقی سرور پر استعمال سے پہلے ماہر ڈویلپر سے HTTPS، secrets، admin account creation، access control، backups اور data sync کی مکمل جانچ کروائیں۔
